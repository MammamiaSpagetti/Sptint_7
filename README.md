# API-тесты сервиса «Яндекс Самокат»

Учебный проект автоматизированных API-тестов для сервиса «Яндекс Самокат».
Тесты проверяют создание и авторизацию курьера, создание заказа с разными
вариантами цвета и получение списка заказов.

## Структура проекта

```text
project/
├── tests/
│   ├── test_create_courier.py  # тесты создания курьера
│   ├── test_login_courier.py   # тесты авторизации курьера
│   ├── test_create_order.py    # тесты создания заказа
│   └── test_get_orders.py      # тест получения списка заказов
├── conftest.py                 # фикстуры создания и удаления курьеров
├── helpers.py                  # отдельные функции регистрации и удаления курьера
├── urls.py                     # базовый URL и адреса ручек API
├── data.py                     # тестовые данные и ожидаемые тела ответов
├── requirements.txt            # зависимости проекта
├── pytest.ini                  # настройки поиска тестов
├── README.md                   # инструкция по работе с проектом
├── .gitignore                  # исключения для Git
└── allure-report/              # готовый HTML-отчёт Allure
```

## Установка

Создать виртуальное окружение:

```bash
python -m venv venv
```

Активировать окружение на Windows:

```bash
venv\Scripts\activate
```

Установить зависимости:

```bash
pip install -r requirements.txt
```

## Запуск тестов

Запустить тесты с подробным выводом:

```bash
pytest -v
```

Запустить тесты и сохранить промежуточные результаты Allure:

```bash
pytest --alluredir=allure-results
```

## Allure-отчёт

Создать готовый HTML-отчёт из промежуточных результатов:

```bash
allure generate allure-results -o allure-report --clean
```

Открыть готовый отчёт:

```bash
allure open allure-report
```

Для временного просмотра отчёта также можно использовать:

```bash
allure serve allure-results
```

Для загрузки в репозиторий нужна папка `allure-report`, созданная командой
`allure generate`. Папка `allure-results` содержит промежуточные данные и
добавлена в `.gitignore`.

Git-команды, создание репозитория и загрузку проекта на GitHub пользователь
выполняет самостоятельно.
